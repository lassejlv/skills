# Starter rules

Standing rules from Lasse that are not tied to one project. Copy the ones that fit into the new board's Rules section, under "From the user", with the date you add them. Adjust names to the project. Rules from this project's own people and docs go next to them.

## Communication

- Reply in the user's language (Lasse: Danish). Code, commits, pull requests and comments follow the project's language.
- Act on direct orders with sensible defaults and say which default was chosen. Ask only about real unknowns or irreversible steps. "don't ask option questions".

## Permission

- Post nothing outside without an OK: no pushes, pull requests, comments, issues or messages. "Ik post noget på github uden min tilladelse". A confirmed step counts for that step only.
- Never merge. The person who owns the repository approves and merges, and Lasse tests and reviews. "ikke MERGE!!!! det vigtigt."
- Never push to the main branch.
- Force-push only on own feature branches, and ask first when a branch is already pushed.
- Never mention Claude or Claude Code in commits, pull requests or comments: no attribution, session links or "generated with" lines.

## Secrets

- Never print, commit or post tokens, credentials or personal data. Do not read token files or pull credentials out of a credential helper.

## How the work is done

- Research deeply: pull all repositories, check for news and read every reference in full before starting. Do not rely on what a summary says about a file.
- Test end to end on every platform the project supports, and say plainly what was not tested.
- Check that a task really belongs to this team before starting, and assign it to yourself first, so two people do not work on the same thing.
- Before/after recordings and screenshots stay plain: nothing drawn or burned in. Labels go in the text next to them.
- Report outcomes faithfully. A failing test, a skipped step or a wrong earlier statement gets said out loud.

## Time

- When the project has a timer or timesheet, keep the timer on the task being worked on, switch it when the task changes, and stop it when the user stops. Report hours only from what the user confirms.
