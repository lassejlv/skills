# Components

### Basic Components

- [Accordion](https://gpui-kit.com/accordion) - Collapsible content panels
- [Alert](https://gpui-kit.com/alert) - Alert messages with different variants
- [Attachment](https://gpui-kit.com/attachment) - File and media attachment surfaces
- [Avatar](https://gpui-kit.com/avatar) - User avatars with fallback text
- [Badge](https://gpui-kit.com/badge) - Count badges and indicators
- [Bubble](https://gpui-kit.com/bubble) - Chat message surface with alignment and reactions
- [Button](https://gpui-kit.com/button) - Interactive buttons with multiple variants
- [Checkbox](https://gpui-kit.com/checkbox) - Binary selection control
- [Collapsible](https://gpui-kit.com/collapsible) - Expandable/collapsible content
- [DropdownButton](https://gpui-kit.com/dropdown_button) - Button with dropdown menu
- [Icon](https://gpui-kit.com/icon) - Icon display component
- [Image](https://gpui-kit.com/image) - Image display with fallbacks
- [Kbd](https://gpui-kit.com/kbd) - Keyboard shortcut display
- [Label](https://gpui-kit.com/label) - Text labels for form elements
- [Marker](https://gpui-kit.com/marker) - Conversation status and separator marker
- [Message](https://gpui-kit.com/message) - Composable chat message structure
- [MessageScroller](https://gpui-kit.com/message-scroller) - Tail-following virtualized message list
- [Pagination](https://gpui-kit.com/pagination) - Page navigation controls
- [Progress](https://gpui-kit.com/progress) - Progress bars
- [Questionnaire](https://gpui-kit.com/questionnaire) - Composable multi-step questions and answers
- [Radio](https://gpui-kit.com/radio) - Single selection from multiple options
- [Rating](https://gpui-kit.com/rating) - Interactive star rating component
- [Skeleton](https://gpui-kit.com/skeleton) - Loading placeholders
- [Slider](https://gpui-kit.com/slider) - Value selection from a range
- [Spinner](https://gpui-kit.com/spinner) - Loading and status spinners
- [Stepper](https://gpui-kit.com/stepper) - Step-by-step progress indicator
- [Switch](https://gpui-kit.com/switch) - Toggle on/off control
- [Tag](https://gpui-kit.com/tag) - Labels and categories
- [TextView](https://gpui-kit.com/text-view) - Markdown and HTML text rendering
- [Toggle](https://gpui-kit.com/toggle) - Toggle button states
- [Tooltip](https://gpui-kit.com/tooltip) - Helpful hints on hover

### Form Components

- [Input](https://gpui-kit.com/input) - An input field or a component that looks like an input field.
- [Textarea](https://gpui-kit.com/textarea) - Multi-line text with fixed rows or auto-grow.
- [Editor](https://gpui-kit.com/editor) - Source-code editing with highlighting, gutter, and folding.
- [Select](https://gpui-kit.com/select) - A list of options for the user to pick.
- [Combobox](https://gpui-kit.com/combobox) - Searchable single-select or multi-select dropdown.
- [NumberInput](https://gpui-kit.com/number-input) - Numeric input with increment/decrement
- [DatePicker](https://gpui-kit.com/date-picker) - Date selection with calendar
- [TimeField](https://gpui-kit.com/time-field) - Segmented time-of-day input
- [OtpInput](https://gpui-kit.com/otp-input) - One-time password input
- [ColorPicker](https://gpui-kit.com/color-picker) - Color selection interface
- [Form](https://gpui-kit.com/form) - Form container and layout

### Layout Components

- [DescriptionList](https://gpui-kit.com/description-list) - Key-value pair display
- [GroupBox](https://gpui-kit.com/group-box) - Grouped content with borders
- [Root](https://gpui-kit.com/root) - Window-level provider for themes, dialogs, and notifications
- [Theme](https://gpui-kit.com/theme) - Customize colors, typography, and light/dark appearance
- [Dialog](https://gpui-kit.com/dialog) - Dialog and modal windows
- [Notification](https://gpui-kit.com/notification) - Toast notifications
- [Popover](https://gpui-kit.com/popover) - Floating content display
- [Resizable](https://gpui-kit.com/resizable) - Resizable panels and containers
- [Scrollable](https://gpui-kit.com/scrollable) - Scrollable containers
- [Sheet](https://gpui-kit.com/sheet) - Slide-in panel from edges
- [Sidebar](https://gpui-kit.com/sidebar) - Navigation sidebar
- [StatusBar](https://gpui-kit.com/status-bar) - Bottom status bar with left/center/right regions
- [Toolbar](https://gpui-kit.com/toolbar) - Top toolbar with left/right regions and sizes

- [Calendar](https://gpui-kit.com/calendar) - Calendar display and navigation
- [Carousel](https://gpui-kit.com/carousel) - Browse through a set of related items
- [Command](https://gpui-kit.com/command) - Command palette for search and quick actions

- [Menu](https://gpui-kit.com/menu) - Menu and context menu and dropdown menu.

- [Tree](https://gpui-kit.com/tree) - Hierarchical tree data display
- [VirtualList](https://gpui-kit.com/virtual-list) - Virtualized list for large datasets
